# Code of Conduct

## Our commitment

We are committed to a respectful, inclusive, and technically honest community. Participation should make it easier for people with different backgrounds and levels of experience to contribute safely.

## Expected behavior

- Be respectful and specific when discussing ideas, code, prompts, and evidence.
- Critique behavior and artifacts rather than people.
- State uncertainty, assumptions, limitations, and conflicts of interest.
- Protect private prompts, credentials, personal data, and unpublished security details.
- Respect maintainers' decisions about project scope, security boundaries, and evidence requirements.
- Accept correction and help make discussions useful to future contributors.

## Unacceptable behavior

- Harassment, threats, discrimination, personal attacks, or sexualized attention.
- Publishing another person's private information without permission.
- Posting credentials, private prompts, customer data, or vulnerability details in public channels.
- Deliberately misrepresenting validation evidence, professional authority, standards, or project capabilities.
- Repeated disruption, spam, or attempts to bypass project security and contribution processes.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions, and other spaces where someone is representing this project.

## Reporting and enforcement

For security vulnerabilities, follow `SECURITY.md` instead of using a public issue.

For conduct concerns, contact the repository owner through the GitHub profile and request a private channel before sharing sensitive personal details. Maintainers may edit or remove contributions, restrict participation, or take other proportionate action to protect the community.

Reports will be handled as privately as reasonably possible, but no fixed response-time commitment is currently offered.
